## SR-1 · Jensen 不等式缺假设
- **原文**：「由此归纳得到 **Jensen 不等式**：若 $\lambda_i \ge 0$、$\sum_i \lambda_i = 1$，则 $$f\Bigl( \sum_i \lambda_i x_i \Bigr) \le \sum_i \lambda_i f(x_i)$$」
- **问题**：没有写 $x_i \in I$，也没有说明指标集有限（「归纳」只给出有限和）。凸函数 $f$ 只定义在区间 $I$ 上，$\sum \lambda_i x_i$ 是否落在 $I$ 内取决于 $x_i \in I$。
- **建议**：「设 $x_1, \ldots, x_n \in I$，$\lambda_1, \ldots, \lambda_n \ge 0$ 且 $\sum_i \lambda_i = 1$，则 …」。（翻译侧：模型已如实报告并未擅自补上。）

## SR-2 · 行列式存在唯一性·证法一首句疑似损坏
- **原文**：「记 $D(e_1, \ldots, e_n) = 1$ 决定了规范的零点。」
- **问题**：「规范的零点」不通顺，可能是「规范化」之误（第三条公理 $D(e_1,\ldots,e_n)=1$ 起固定规范的作用）。语境里没有「零点」概念。
- **建议**（待作者确认原意）：「第三条公理 $D(e_1, \ldots, e_n) = 1$ 固定了 $D$ 的规范化。」
- **翻译侧记录**：pilot 的模型译作 "determine the canonical normalization"，**静默改写**且未在 `ambiguities` 报告——见 `_audit/llm-store/pilot1-review.json`。忠实译法应为字面译出并标注（"canonical zero point"，附说明）。此类静默修复确定性校验器**抓不到**（不能声称能可靠发现），所以提示词已加硬规则、并设计了第二遍语义初筛实验。

## SR-3 · 证法一·「每一项对每个 $a_{ij}$ 都是一次的」
- **原文**：「多重线性（每一项对每个 $a_{ij}$ 都是一次的，而 $a_{ij}$ 关于 $v_j$ 线性）」
- **问题**：展开式的每一项是 $a_{\sigma(1),1}\cdots a_{\sigma(n),n}$，对**每一列**的坐标恰好是一次的，但对**单个** $a_{ij}$ 是 0 次或 1 次，不是「都是一次」。
- **建议**：「每一项对第 $j$ 列的坐标 $(a_{1j},\ldots,a_{nj})$ 恰好是一次的，而 $a_{ij}$ 关于 $v_j$ 线性」。

## SR-4 · 谱定理（矩阵版 ⟹ 算子版）·「正规性逐项传递」
- **原文**：「取标准正交基把 $T$ 写成 $A$，正规性逐项传递：$A^{*}A = AA^{*}$。」
- **问题**：「逐项」暗示按矩阵元素逐个检验，论证并不如此；真正的理由是：在标准正交基下 $T^{*}$ 的矩阵是 $A^{*}$（共轭转置），所以 $T^{*}T = TT^{*}$ 直接给出 $A^{*}A = AA^{*}$。
- **建议**：「在标准正交基下 $T^{*}$ 的矩阵是 $A^{*}$，故 $T^{*}T = TT^{*}$ 给出 $A^{*}A = AA^{*}$。」

## SR-5 · 谱定理（算子版 ⟹ 矩阵版）·$\Lambda$ 未交代
- **原文**：「…由 $AU = U\Lambda$ 得 $U^{*}AU = \Lambda$ 对角。」
- **问题**：$\Lambda$ 第一次出现时没有说明是由特征值构成的对角矩阵。（低优先级的清晰度问题。）
- **建议**：在取特征基时补一句「设对应特征值为 $\lambda_1,\ldots,\lambda_n$，$\Lambda = \operatorname{diag}(\lambda_1,\ldots,\lambda_n)$」。

## SR-6 · Lax–Milgram·「与本图内积约定一致」
- **原文**：「**半双线性**：$L$ 对第一变量线性，对第二变量共轭线性（与本图内积约定一致）；」
- **问题**：违反内容准则（AGENTS §4：节点正文不得出现「本图约定」之类指代）。读者拿不到「本图」。
- **建议**：直接写出约定：「（与内积的约定一致：$\langle\cdot,\cdot\rangle$ 对第一变量线性、对第二变量共轭线性）」——**前提**是作者确认内积节点确实采用这一约定。
